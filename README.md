# NSE Stock Price Tracker

This application is a graphical user interface (GUI) built using Python tkinter library to track and display stock prices from the NSE (National Stock Exchange). It fetches historical stock data, displays key metrics, and plots a stock price chart for a specified period.

# Features

- **Real-Time Stock Data**: Fetch the latest stock prices, day high, day low, and opening prices.
- **Stock Trends**: View a graphical chart of stock prices over different periods (1 day, 5 days, 1 month, etc.).
- **P/E Ratio Display**: Shows the Price-to-Earnings (P/E) ratio if available.
- **User-Friendly Interface**: Simple and intuitive GUI using Tkinter.
